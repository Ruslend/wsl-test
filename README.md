# OfficeFlow

Учебный MVP корпоративной системы заявок сотрудников: IT-доступы, оборудование и внутренние сервисы.

## Возможности

- создание заявки сотрудником;
- статусы «Новая», «В работе», «Выполнено»;
- приоритеты и фильтрация;
- поиск по названию, отделу и сотруднику;
- dashboard со статистикой;
- REST API и хранение данных в SQLite;
- адаптивный интерфейс;
- автоматические unit-тесты.

## Технологии

Python 3.10+ (только стандартная библиотека), SQLite, HTML, CSS, JavaScript.

## Запуск

```bash
python server.py
```

Открыть в браузере: `http://127.0.0.1:8000`

## Тесты

```bash
python -m unittest discover -s tests -v
```

## API

- `GET /api/tickets` — список заявок;
- `GET /api/tickets?status=new&search=CRM` — фильтрация;
- `POST /api/tickets` — создание заявки;
- `PATCH /api/tickets/{id}` — изменение статуса;
- `GET /api/stats` — статистика.

## Что можно добавить дальше

Авторизацию и роли, PostgreSQL, журнал изменений, комментарии, вложения, уведомления, Docker и CI/CD.
